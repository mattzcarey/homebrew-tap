# mattzcarey/homebrew-tap

Homebrew formulae for my software.

```sh
brew install mattzcarey/tap/everystate
```

| Formula | What it is |
|---|---|
| [`everystate`](https://github.com/mattzcarey/everystate) | TLA+ model checker with a TLC-compatible command line |

Formulae install the prebuilt binaries from each project's GitHub release, for macOS and Linux on arm64 and x86-64. The Bump workflow updates them within an hour of a release.
